# Hev-Match

# 📋Descripción.
 Hev-Match es un proyecto personal  de JS tematizado del clasico videojuego de half life del 98   en donde se generaran cartas pares de 6,8 o 12, el objetivo del juego es encontrar todas las parejas antes de que se termine el tiempo, si termina el tiempo antes de encontrar todas las parejas  el jugador pierde. 
# 🎯 Objetivos
     1️⃣.Conseguir soltura con JS
     2️⃣.Manejar las etiquetas esenciales 
     3️⃣. Ganar la confianza que necesito.
